# 📘 Полный гид по GitHub для Web3-инвестора + База для прокачки

Этот репозиторий — практическое руководство и единый навигационный хаб для правильного прогрева GitHub-аккаунта, набора социальной репутации и безопасной работы в экосистеме Web3.

---

## 1. Краткая суть: Зачем криптоинвестору GitHub и подписчики?

**GitHub** — крупнейшая в мире платформа для разработчиков, где хранится открытый код почти всех блокчейнов и криптопроектов. Для участника ретродропов и Web3-активностей живой GitHub — это «цифровой паспорт высшей категории», который доказывает проектам, что за вашим кошельком стоит реальный человек и строитель экосистемы (Builder), а не ферма ботов.

**Что дает прокачанный профиль и подписчики (Followers):**
* **Прохождение анти-сибил фильтров (Anti-Sybil):** Проекты отсеивают «сибилов» (людей, создающих десятки пустых кошельков ради наград). Живой GitHub с историей действий, репозиториями и подписчиками автоматически переводит ваш профиль в категорию доверенных пользователей.
* **Максимальные баллы в системах репутации (Gitcoin Passport, Talent Protocol):** Агрегаторы репутации напрямую считывают возраст вашего GitHub, количество подписчиков, созданных репозиториев и дней активности.
* **Доступ к кранам (Faucets) в тестнетах:** Большинство тестовых сетей требуют авторизацию через GitHub перед выдачей бесплатных тестовых монет. Пустые аккаунты получают отказ, а прокачанные профили забирают токены без ограничений.
* **Мультипликаторы на ретродропах:** Крупные блокчейны и L2-сети регулярно выделяют повышенные награды тем, кто разворачивал смарт-контракты и вел активность на GitHub.

### Словарь базовых терминов простыми словами
* **EVM (Ethereum Virtual Machine):** «Движок», на котором работают Ethereum и большинство популярных сетей (Base, Ink, Arbitrum, Optimism, Polygon). Кошелек и смарт-контракты во всех этих сетях устроены одинаково.
* **Газ (Gas):** Комиссия блокчейна, которую вы платите за выполнение любой транзакции или деплой контракта.
* **Аппрув (Approve):** Разрешение, которое вы подписываете в кошельке, позволяя смарт-контракту взаимодействовать с конкретным токеном на вашем балансе.
* **Репозиторий (Repo):** Папка вашего проекта на GitHub, где хранятся файлы, код или текстовые заметки.
* **Коммит (Commit):** Сохранение изменений в вашем репозитории. Каждый коммит закрашивает зеленый квадратик в вашем календаре активности.
* **Звезда (Star):** Аналог «лайка» или добавления полезного чужого проекта в закладки.
* **Форк (Fork):** Копирование чужого открытого репозитория к себе в профиль (как репост, который можно самостоятельно редактировать).

## 2. Подготовка: Что понадобится перед стартом

1. **Надежная почта (желательно Gmail):** На нее будут приходить коды подтверждения и важные уведомления безопасности.
2. **Приложение для двухфакторной защиты (2FA):** Google Authenticator или Authy (GitHub обязательно требует включения 2FA у активных аккаунтов).
3. **Уникальная аватарка и описание:** Любая качественная картинка или NFT, понятный никнейм и заполненная строка «О себе» (Bio), например: *Web3 enthusiast & EVM explorer*.
4. **Рабочий EVM-кошелек (Rabby или MetaMask):** Его публичный адрес (`0x...`) или доменное имя (`.eth` / `.ink`) понадобится для связки с Web3-платформами репутации (Talent Protocol, Gitcoin, Lens).

## 3. Пошаговый план: Как правильно прокачивать аккаунт (Anti-Sybil)

Главный принцип успешной прокачки — **естественность (Anti-Sybil)**. Алгоритмы защиты GitHub мгновенно блокируют аккаунты, которые за 5 минут ставят 50 звезд, подписываются на 100 человек и исчезают на полгода. Такие профили получают скрытую метку теневого бана (`flagged`) и перестают отображаться у других пользователей.

### Шаг 1. Оформление и защита профиля (День 1)
1. Откройте настройки профиля (**Settings** -> **Public profile**): загрузите аватарку, укажите имя, город/локацию и короткое описание в поле **Bio**.
2. Перейдите в раздел **Password and authentication** и включите **Two-factor authentication (2FA)** через приложение-аутентификатор, обязательно сохранив резервные коды (Recovery codes) в бумажном блокноте.
3. Создайте свой первый публичный репозиторий (кнопка **+** в правом верхнем углу -> **New repository**), отметьте галочкой **Add a README file** и напишите в нем пару строк о своих интересах в Web3.

### Шаг 2. Органичная активность: Звезды и Форки (С паузами между днями)
1. Заходите в аккаунт 2–3 раза в неделю, обязательно делая естественные паузы между днями активности.
2. Переходите по ссылкам на крупные блокчейн-проекты из базы ниже, открывайте файлы кода на 1–2 минуты и ставьте **2–4 звезды (Star)** за один сеанс.
3. Сделайте **1–2 форка (Fork)** фундаментальных библиотек (например, OpenZeppelin или Uniswap) к себе в профиль — кнопка **Fork** находится в правом верхнем углу страницы проекта.

### Шаг 3. Набор подписчиков и зеленая сетка коммитов (Постоянно)
1. **Подписки на лидеров индустрии:** За один заход подписывайтесь на 3–5 реальных разработчиков из списка инфлюенсеров ниже.
2. **Взаимные подписки внутри клуба:** Подписывайтесь на коллег постепенно — не более 2–3 человек в день в разное время суток, обязательно сочетая это с просмотром чужих репозиториев.
3. **Зеленые квадратики (Contributions):** Раз в несколько дней редактируйте файл `README.md` в своем репозитории (значок карандаша), добавляйте туда новую полезную ссылку или заметку и нажимайте **Commit changes**.
4. **Сохранение своих смарт-контрактов:** Когда вы разворачиваете разные смарт-контракты в сетях (Base, Ink, Arc и др.) через Remix, создавайте в своем репозитории файл с расширением `.sol` (например, `Vault.sol`) и сохраняйте туда исходный код контракта. Наличие уникальных `.sol` файлов в профиле — сильнейший маркер реального билдера.

## 4. Безопасность (Критично!)

* **Никогда не публикуйте сид-фразы и приватные ключи:** Самая опасная ошибка новичков на GitHub — случайно загрузить в публичный репозиторий текстовый файл или конфиг (`.env`), внутри которого записана сид-фраза или приватный ключ от кошелька. Боты-снайперы сканируют все новые коммиты на GitHub за секунду и мгновенно крадут средства. В репозиториях можно публиковать **только публичный адрес** кошелька (`0x...`) или адрес смарт-контракта.
* **Не скачивайте и не запускайте чужой код на своем ПК:** Мошенники создают сотни фейковых репозиториев с названиями «Auto-Airdrop-Bot» или «Crypto-Sniper». Внутри таких архивов спрятаны вирусы-стилеры, ворующие доступ к браузеру и кошелькам. Для прокачки профиля только просматривайте код в браузере, ставьте звезды или делайте безопасный веб-форк.
* **Гигиена кошелька и Anti-Sybil на балансе:** При подключении GitHub и кошелька к Web3-платформам (Gitcoin, Talent, Galxe) всегда проверяйте домен сайта, не подписывайте подозрительные транзакции (`Approve` на неизвестные контракты) и никогда не выводите баланс «под ноль». Всегда держите на кошельке **неснижаемый остаток на газ** (минимум $5–10 в нативном токене сети), используйте **неровные суммы** при переводах и взаимодействуйте с **разными смарт-контрактами** с паузами между днями.
